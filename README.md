# GradGateway Frontend

This repository contains the Next.js frontend for GradGateway, a modern hiring and talent discovery platform built for Sri Lankan undergraduates and recruiting companies.

## What this frontend provides

- Student and company registration flows
- Public landing pages and marketing content
- Student dashboards for projects, applications, and opportunities
- Company dashboards for recruiting and talent discovery
- Messaging, notifications, and application tracking experiences

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- shadcn/ui
- Firebase
- SignalR

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the app in your browser:
   ```text
   http://localhost:3000
   ```

## Useful commands

```bash
npm run build
npm run lint
npm run dev
```

## Notes

- This frontend expects the backend API to be running and reachable for data-driven features.
- The app uses environment and API configuration files for service endpoints and integrations.
